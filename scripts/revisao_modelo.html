Revisão dos Tipos de veículo

Cada recorte veio do Moondream 3 com uma classe. Corrija só o que estiver errado: clique na classe certa, ou passe o mouse no recorte e tecle c carro (inclui SUV e minivan), p pickup, v van, k caminhão, o ônibus (inclui micro-ônibus), x descartar (não é um veículo inteiro: pedaço, sombra, grupo de carros). O progresso fica salvo neste navegador. No fim, exporte o CSV para a pasta tipos-de-veiculo/. A etiqueta "corrigido" marca o que você mudou.
